Próxima etapa do gerador

Preparar lista de convidados

Use este padrão para organizar a planilha que será importada para criar os convites individuais.

Como preencher

  1. grupo: código único da família ou grupo que receberá um link.
  2. responsavel: nome da pessoa responsável pelo convite.
  3. participante: nome de cada pessoa do grupo, uma por linha.
  4. tipo: use ADULTO ou CRIanca (criança).
  5. idade: idade em anos completos para crianças; deixe vazio para adultos.

Se uma família tiver três participantes, use três linhas com o mesmo código de grupo. O link será associado ao grupo, não a cada linha.

Exemplo de uma linha

Cabeçalho e uma linha preenchida:

gruporesponsavelparticipantetipoidade
FAM-001Mariana SouzaMariana SouzaADULTO—

Atenção: mantenha o mesmo código em todas as linhas da mesma família.
